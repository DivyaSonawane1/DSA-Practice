## 📖 About

This repository contains my Data Structures and Algorithms (DSA) practice solutions implemented in **Java**.

The goal of this repository is not only to solve problems but also to document the thought process behind each solution. Every problem is organized and explained to strengthen problem-solving skills and prepare for coding interviews.

## 📝 Problem Format

Each `.md` file follows a structured format:

### Problem Name

* Problem Description
* Examples
* Constraints
* Approach / Explanation
* Time Complexity
* Space Complexity
* Java Solution

This format helps in understanding the reasoning behind the solution rather than simply memorizing code.
